# dns-parser

Распределённый парсер каталогов dns-shop.ru: браузерные воркеры (Camoufox/Playwright) за ротацией прокси, очередь задач [simple-task-manager](https://github.com/Andrey-Ultra/simple-task-manager), веб-панель управления, всё в Docker Compose.

## Компоненты

- **panel** (`server/panel`) — веб-интерфейс на FastAPI, http://localhost:8000:
  - **Прокси** — текстовое поле со списком `ip:port:login:password`. «Обновить список» удаляет прокси, которых нет в поле, и добавляет новые.
  - **Задачи** — текстовое поле со ссылками на каталоги. «Отправить на выполнение» отменяет все прошлые задачи (вместе с результатами) и ставит новый список. Таблица показывает статус каждой ссылки.
  - **CSV** — скачивается в любой момент: пока не всё готово, файл называется `…-partial.csv` и содержит только готовые ссылки. Формат как в старом `cli/script.py` (`;`, UTF-8 с BOM, без заголовка).
  - **Воркеры** — создать, посмотреть логи, удалить. Каждый воркер — отдельный контейнер с браузером; панель управляет ими через Docker (`/var/run/docker.sock`).
- **worker** (`server/worker`) — берёт ссылку из очереди, прокси из proxy-giver, открывает каталог в Camoufox (виртуальный дисплей Xvfb), скроллит до конца и возвращает JSON с товарами. При ошибке задача возвращается в очередь.
- **stm** — очередь задач (собирается из GitHub). `TASK_TIMEOUT=600`: если воркер не ответил за 10 минут, задача возвращается в очередь.
- **proxy-giver** (`server/proxy-giver`) — раздаёт прокси воркерам по кругу.

## Запуск

Нужны Docker и Docker Compose.

```bash
cd server
docker compose up -d --build
```

Откройте http://localhost:8000, вставьте прокси, создайте воркеров, отправьте ссылки.

Порты: панель `8000`, очередь `8080`, proxy-giver `9001`.

Остановка: сначала удалите воркеров в панели (их создаёт панель, а не compose), затем:

```bash
docker compose down
```

Если воркеры остались, удалить их можно так: `docker rm -f $(docker ps -aq --filter label=dns-parser.role=worker)`.

## Ограничения

- Прокси и очередь хранятся в памяти: после перезапуска `proxy-giver` список прокси надо обновить в панели заново, после перезапуска `stm` незавершённые задачи станут «потерянными» — отправьте список ещё раз. Готовые результаты панель хранит на томе `panel-data`.
- Если ссылка падает каждый раз (например, блокировка), задача будет возвращаться в очередь бесконечно — смотрите логи воркера.
- В панели нет авторизации, а через неё доступен Docker. Не открывайте порт 8000 наружу.

## CLI

`cli/submit.py` — отправить одну ссылку и следить за статусом без панели:

```bash
pip install "simple-task-manager-client @ https://github.com/Andrey-Ultra/simple-task-manager/archive/refs/heads/main.zip#subdirectory=python"
python cli/submit.py https://www.dns-shop.ru/catalog/17a89d9b16404e77/veb-kamery/
```

`cli/script.py` и `cli/main.py` — старая схема на Redis, с новым сервером не работают.
